# go-ionomaps v0.1.0's public API, reviewed for a host developer (watchpost D-216)

Up: [design](design.md) · [rulings](../02-analysis/rulings.md)

**What this is.** Before v0.1.0-rc.1 is tagged (watchpost D-206), the public API was read as a host
developer meets it: the names, the shape of each call, and how easily a host invokes it. Every change
is made before the tag, each listed in the table below and in the build log.

## Made

| Before | After | Why |
|---|---|---|
| `Snapshot.Hours []Hour`, documented as up to 25 hours, always one | `Snapshot.Now Hour` | a field that always holds one value should not be a slice a host indexes (`Hours[0]`); the documentation was false (BUILD red team C-11) |
| `Snapshot.Ahead(k) (Hour, error)`, a bare hour a host splices into the snapshot | `Snapshot.Ahead(k) (Snapshot, error)`: the hour k ahead as a snapshot of its own, typical, carrying no live disturbance or offset | the answers are methods on a snapshot, so an hour ahead must be one; the splice carried today's D-RAP disturbance into a typical hour (L-F2) |
| `At`, `Bands`, `Path`, `Reach` each take `at time.Time` and pick the hour that holds it | each answers for its snapshot's hour: `s.Readings(places)`, `s.Bands(origins, radiusKm)`, `s.Path(from, to)`, `s.Reach(origin, mhz)` | a snapshot is one hour now, so the moment is redundant, and its window was a trap (L-F14: one minute before `Computed` was refused). The sun is now the snapshot's own moment (`Now.At`), not the host's clock: an answer reads the fields and the sun of the same moment, and the host already says the snapshot's age and when it is stale (watchpost FR-5.1) |
| `Snapshot.At(points, at)` | `Snapshot.Readings(places)` | "At" read as a time, not as "the readings at these places" |
| `Snapshot.Early Reason` | `Snapshot.Reason Reason` | `s.Reason == ionomaps.TooSoon` reads as what it is |
| `(*Library).Sources()`, which ignored its receiver | `ionomaps.Sources()` | static data reached through an instance made hosts build a library to read a list (C-5) |
| `Band`, `Status`, `Limit` with no names | `String()` on each ("20m", "open", "MUF") | a host keys its rows by band, not by position in a slice, and logs read (L-F8) |
| `Inputs.Refused`, which listed NOAA files fetched but unreadable, nothing refused | `Inputs.Unread`, the meaning unchanged | the name said a refusal where there was none (watchpost round 2 CN2-15, D-229; v0.1.0-rc.3) |
| `Bitset.Set`, exported on an immutable snapshot | unexported; `Field.WithNoData(cells ...int) Field` returns a copy with those cells marked | a host could write into a snapshot documented as immutable (C-20); a host's tests still need no-data cells (L-F11) |
| errors as text only; a stopped update said "too soon" | `ErrNoField`, wrapped, whenever there is no field to give, with the context's own error wrapped beside it when the host's cancel stopped the update; the reason `Unfinished` for a snapshot built from what is held after a cancel, or after a deadline that left no room for any ask (`ErrNoRoom`, below) | a host tells a slow link (`context.DeadlineExceeded`) from a closed mode (`context.Canceled`) and from NOAA's refusal without reading text; a library sentinel per cause would have duplicated the context's own (L-F4) |
| - | `UpdateOptions.NoStations`, and `Inputs.NoStations` saying so | GIRO never asked and no reading on the field, for a host GIRO's terms do not cover (watchpost D-214) |
| an hour ahead at the snapshot's moment plus k hours, rebuilt at every ask | the climatology at the start of that UTC hour (`Hour.At` the hour's start), kept by the library and shared by its snapshots | R-1.3 says the hours ahead are the day's cache's hours; at the snapshot's moment no two snapshots shared one, so every ask rebuilt it, about 35 ms (watchpost D-222, P-4, A-23) |
| - | `(*Library).State() []byte` and `(*Library).Restore([]byte) error` | GIRO's throttle state kept across a host's restarts (watchpost D-213). `Restore` is its own call, not an option to `New`, so a state file that fails its checks (`ErrBadState`) never stops a host from starting. A state this library did not write leaves it as it was; otherwise GIRO's part and the F10.7 mean are taken each on its own, `ErrBadGIROState` or `ErrBadMean` naming the part refused, and the host carries on |
| `ReachField` under the upper limit only, its `Limit` always the MUF | a cell reached only between the limits, as the band statuses judge it; `Limit` the limit that bounds the reach - the MUF where the lower limit closes no cell under it, else the lower limit that closes the more | the reach said "no skip zone" for a band the chart called absorbed (watchpost D-205) |
| NOAA's unreadable files passed over in silence; GloTEC's gaps uncounted; `GIROPaused` never said; `Rejected` counted since `New` | `Inputs.Unread` (named `Refused` until rc.3) names each file not read, `Inputs.GloTECFilled` counts the cells the climatology filled, `GIROPaused` is said while GIRO backs off, and `Rejected` is the last burst's | a host says what the field is made of and why it is not new, from fields rather than guesses (L-F5, L-F6) |
| `TypicalError.Basis` and `Offset.Basis`, a developer's citation a host read aloud | `Basis` in words a listener can be told, `Source` the citation | watchpost said "PLAN's week (watchpost D-134 ...)" with every hour ahead (AX-3) |
| `Field.CellCentre` | removed | no consumer; the box and the cell counts say it (C-20) |
| `Inputs.Unread` naming NOAA's files fetched and unreadable; an update whose GloTEC index did not come back said `Offline` and GIRO not asked; `Fresh` whatever was missing | `Inputs.Unread` names every file asked for and not read; a new reason, `Partial`, for a snapshot short of any, `Fresh` meaning every file came back; `Offline` only when nothing came back and GIRO was not due; GIRO asked whatever NOAA answered | a GloTEC outage showed the climatology unmoved by any station, said "nothing could be fetched" though NOAA's other files came: "we should never have data mislabelled" (watchpost D-239, D-82; v0.1.0-rc.5) |
| - | `ionomapstest`: `Open(dir, solarFile)` reads recorded days as the evidence's `dry_fetch.py` writes them; `(*Recorded).Replay(Options)` is a `Fetcher` answering from them at a clock (`SetNow`, `Now` as the library's `Clock`), nothing dated after it, any address the library does not ask failing (`ErrUnknownAsk`); `Write(dir, Synthetic)` writes synthetic days for a test | a host can test against recorded days, as `net/http/httptest` serves a handler; no GIRO or NOAA file may be committed, so tests need synthetic days; one implementation for the library's instruments and watchpost's `tools/reachscore`, which each had their own (watchpost D-237, D-79; v0.1.0-rc.4) |
| GIRO's failures said only on the burst's own update, as a pause or nothing | `Inputs.GIRO GIROOutcome` (`GIROAnswered`, `GIROUnavailable`, `GIRODenied`) and `Inputs.StationsFailed`, carried in every snapshot until the next burst | a station failing, GIRO down, and GIRO refusing this host each said for the hour that follows, not as a quiet hour (watchpost D-247) |
| - | `ionomapstest.Options.Answers map[string]Answer` (`Answer{Status, Body, Err}`), keyed by `"GloTEC"`, `"solar"`, `"D-RAP"`, `"scales"` or a station's code; `ionomapstest.DRAPTable` and `ionomapstest.ScalesFile` | a host's tests drive the real library into every state it must say, `Fresh` included, which a replay of `dry_fetch.py`'s days alone never reached (RL-12) |
| an update run into its deadline, said Unfinished, NOAA backed off when the deadline left no room; a burst cut short by the deadline said Fresh | `MinDeadline` (32 s, which asks) and `ErrNoRoom`, wrapped when the deadline leaves no room for any ask, naming the time it had, nothing asked or backed off; `Inputs.StationsNotReached`, the live stations a burst left because the deadline came, asked first next hour | an update never runs into its deadline, so a host learns a too-short deadline from the error, not from NOAA blamed and backed off; a burst cut short is counted, not said Fresh (watchpost D-297, D-298, D-301, D-302; v0.1.0-rc.10 and rc.11) |
| `Path` refusing 64 destinations, its error saying more than 64 | up to 64 destinations, the origin besides | the limit is what the error says (RC-13) |
